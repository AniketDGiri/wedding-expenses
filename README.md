# Wedding Expense Tracker 💒

A beautiful, responsive web application to track wedding expenses with cloud storage support.

## Features
- ✅ Track vendor payments and pending amounts
- ✅ Record which family members paid
- ✅ Filter by paid/pending status
- ✅ Cloud storage with Firebase
- ✅ Fully responsive design for all devices
- ✅ Auto-save with localStorage backup

## Live Demo
[View Live Website](https://yourusername.github.io/wedding-expenses)

## Setup
1. Open `index.html` in your browser
2. For cloud storage: Follow `FIREBASE_SETUP.md`

## Technologies Used
- HTML5
- CSS3 (Responsive Design)
- JavaScript (ES6+)
- Firebase Firestore
